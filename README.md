# SmartExcel Automation

A web application for analyzing Excel sales data through interactive dashboards and key performance indicators.

## Live Demo

**[Open SmartExcel Automation](https://smart-excel-automation.vercel.app/)**

Upload an Excel file and explore your sales data directly from your browser.

## Features

- Excel file upload
- Automatic sales data analysis
- Key performance indicators
- Revenue analysis by product
- Interactive data visualization

## Technologies

- Frontend: React, Vite
- Backend: Python, FastAPI
- Data processing: Pandas, OpenPyXL
- Deployment: Vercel, Render
